# OKOLO · Бриф

Двуязычная (RU/EN) форма-бриф с ветками для студии OKOLO. Чистый HTML/CSS/JS, без сборки, хостинг на GitHub Pages.

- `questions.js` — банк вопросов, ветки и тексты (генерируется из таблицы банка вопросов).
- `extras.js` — визуальные варианты ответов (палитры, шрифты, пары) и доп. тексты интерфейса.
- `app.js` — движок: метки, показ вопросов по условиям, сохранение прогресса в браузере, отправка.
- `config.js` — адрес Google Apps Script (`endpoint`). Пустой адрес = демо-режим.
- `apps-script/Code.gs` — бэкенд: Google Sheets, Drive, Notion, письма. Секреты хранятся в Script properties.
